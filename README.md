# Reproduction

This repository contains data sets to be used with two R guides authored by Joana Reis Vasconcelos and published on Zenodo:
Guide 1: [https://zenodo.org/records/17241804](https://doi.org/10.5281/zenodo.17187714)
Guide 2: [https://zenodo.org/records/17187714](https://doi.org/10.5281/zenodo.17241804)
These data sets are provided to reproduce examples, figures, and analyses presented in the guides.
